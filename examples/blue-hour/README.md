# Blue Hour

TyranoForge のスクリーンショットと動作確認に使うデモです。SVG 背景とシナリオは本リポジトリで制作し、MIT License で提供します。実在の制作中プロジェクトの本文・素材は使っていません。

Tyrano のランタイムや TyranoBuilder の素材は含みません。インストール済みの TyranoBuilder を使って、次のコマンドで一時的なプレイ可能プロジェクトを作成できます。

```sh
node scripts/create-demo.js /path/to/demo-output
```

`review.ks` の未定義ラベルは、診断ビューを紹介するための意図的なエラーです。
